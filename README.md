# 💖 Romantic Apology Website for Ariba

A beautiful, interactive, and emotionally rich apology website created with love, courage, and a sorry heart.

## ✨ Features

### Scene 1: Playful Pop-up
- "My Bebo 🥺💖 Are you sad with me?" prompt
- YES/NO buttons with playful interaction
- NO button dodges the cursor with teasing messages
- Heart particle burst on YES click

### Scene 2: Affection Pop-up  
- "That's why you are MY BEBO 💗✨" message
- Sparkle animations and mini confetti
- Smooth bounce-in animation

### Scene 3: Emotional Apology Letter
- Beautiful glassmorphism letter card
- Heartfelt personalized apology message
- Floating hearts and sparkles
- Animated paragraph reveals

### Scene 4: Gift Game
- 9 interactive gift boxes in a 3x3 grid
- Hover animations with bounce and sparkle
- Click to open with confetti explosion
- Fireworks celebration
- Surprise prize reveal modal

### Scene 5: Outfit Selection
- Gallery of 7 beautiful outfit options
- Hover zoom and glow effects
- Click to select with confetti celebration

### Final Scene: WhatsApp Love Delivery
- Animated heart and loading sequence
- Auto-redirect to WhatsApp with love message

## 🎨 Design Features

- **Romantic pastel gradient** (pink, lavender, peach)
- **Glassmorphism UI components** with blur effects
- **Floating hearts** background animation
- **Sparkles** and glow effects throughout
- **Cursor heart trail** on mouse movement
- **Elegant typography** (Dancing Script + Poppins + Playfair Display)

## 🎵 Audio

- Background romantic instrumental music
- Music toggle button (top-right corner)
- Gentle volume setting
- Autoplay on first user interaction

## 📱 Mobile Optimized

- Responsive design (mobile-first)
- WhatsApp-friendly for easy sharing
- Touch-friendly interactions
- Vibration feedback on buttons
- Smooth scrolling

## 🛠️ Tech Stack

- **HTML5** - Semantic structure
- **CSS3** - Modern styling with animations
- **JavaScript (ES6+)** - Interactive functionality
- **GSAP** - Professional animations
- **Canvas Confetti** - Confetti and fireworks effects
- **Google Fonts** - Beautiful typography

## 🚀 Usage

1. Open `index.html` in a web browser
2. For best experience, view on mobile or share via WhatsApp
3. Click through the interactive scenes
4. Enjoy the romantic journey!

# Website

## Deploy

This repo deploys `public/` to **GitHub Pages** using **GitHub Actions**.

### One-time setup (in GitHub)

1. Go to **Settings → Pages**
2. Under **Build and deployment**, select **Source: GitHub Actions**

### Deploy

- Push to `main` (or run the workflow manually via **Actions → Deploy to GitHub Pages**).

After the first successful run, your site will be available at the repository’s GitHub Pages URL (typically `https://<org-or-user>.github.io/<repo>/`).

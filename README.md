# Website-built-

A premium, romantic apology microsite for **Ariba** (HTML/CSS/JS + GSAP), with:

- Interactive multi-scene flow (playful popup → affirmation → apology letter → gift game → outfit selection)
- Pastel romantic gradient, glassmorphism, hearts, sparkles, glow
- **Soft background “instrumental”** (Web Audio synth) that starts on **first user interaction**
- Floating **music toggle** (top-right)
- Canvas **confetti + fireworks**
- Mobile-friendly (WhatsApp-friendly) + smooth transitions
- WhatsApp “love delivery” redirect + attempts **Web Share image attachment** when supported

## Run locally

Any static server works. For example:

```bash
python3 -m http.server 5173
```

Then open `http://localhost:5173` and share the link with Ariba.

# Proposal Website (Basit Chishti × Ronaldo Vibes)

This repo contains a single-page, responsive proposal website for **Basit Chishti** with a fun football/Ronaldo-inspired theme.

## Run it

- **Option A (simplest)**: open `index.html` in your browser
- **Option B (local server)**:

```bash
python3 -m http.server 5173
```

Then visit `http://localhost:5173`.

## Customize

- **Change the text**: edit `index.html`
  - Update the question, timeline items, and signature line
- **Change colors/theme**: edit `styles.css`
- **Change interactions/confetti**: edit `script.js`

## Host on GitHub Pages (optional)

1. Push this repo to GitHub
2. In GitHub: **Settings → Pages**
3. Set source to your default branch and root folder
4. Your site will publish at a GitHub Pages URL
